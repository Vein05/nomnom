# Security Policy

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

Do not open public issues for security vulnerabilities.

Email **man359905@gmail.com** with details. You will receive a response within 48 hours.

If the issue is confirmed, a fix will be released as soon as possible. You will be credited in the release notes unless you request otherwise.
